# 10.16 — System trader

**Status:** ⬜ · **Agent:** C3 · **Size:** 8 SP

**System trader** (design §26.1, §26.4, §26.10; decided by the owner on 2026-10-18): the system seller (sells only the goods of the system sink, never creates goods; proceeds to the treasury main once delivered) and the rule engine of both the system buyer and the seller: rules per item (resources and blueprint items, open to new item types) and side; prices (fixed, floor × factor, market-following, clamped to a minimum and a maximum, optional treasury-health scaling for buying); the buyer's daily spend cap and minimum main balance; per-player daily caps both ways; the seller's reserve stock and the buyer's maximum stock; eligibility (minimum account age, players flagged by 10.10 excluded); schedules (always, time windows, days of the week, date ranges, in a time zone set by admins); named campaigns with priorities and an optional announcement; the global pause; every change audited and applied at a tick boundary. Includes the console page (rules, campaigns, a preview of the expected daily spend and income, the pause), ledger entries for goods leaving the sink, the conservation property in the tests of 10.13, unit and integration tests, a Cypress spec of a campaign that changes a bid in the order book, and a section of the admin documentation in English and Russian

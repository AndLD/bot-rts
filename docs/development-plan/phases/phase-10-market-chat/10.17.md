# 10.17 — Script catalog and product pages

**Status:** ⬜ · **Agent:** C2 · **Size:** 13 SP

**Script catalog and product pages** (design §26.6.1; decided by the owner on 2026-10-19): one place to sell scripts, where a fixed-price edition and a single-copy auction are sold from the same page. **(a) Product pages:** title, category (a typed list in the balance config), summary, a description in a safe Markdown subset cleaned on the server (length limit), up to 6 images (PNG, JPEG, WebP, 2 MB each; re-encoded, metadata stripped), one optional video link to an allowed host shown only after a click; the page outlives its editions and auctions, so a new edition or auction opens from it and its ratings and sales count stay. **(b) Media storage:** an object-storage port with an S3-compatible adapter and a local-disk adapter for development and tests, upload checks (type, size, count), the configuration in `.env.example` and `docs/operations/DEPLOYMENT.md`. **(c) Catalog:** browse and search by title, category and seller, sorted by rating, sales, price or date, open to every signed-in player without a market terminal; buying and listing still need one; `/api/v1` endpoints with the market's API-key scope and catalog reads in the `market` script functions. **(d) Ratings:** 1–5 stars and an optional text, one per copy withdrawn into a drive, editable, not by the seller; averages on the page and the seller's profile; the `ScriptRated` event to the seller. **(e) Resale:** a purchased copy carries its origin and cannot be listed. **(f) Moderation and anti-abuse (design §26.9):** reports of a page, an image or a rating into the moderation queue; admins hide a page (open listings cancelled with refunds), remove an image or a rating, with a reason and audited; new-account limits; rating bursts from linked accounts raise the wash-trading alert. Every write is an engine command; uploads are stored by the API and attached by id. Includes unit and integration tests (Markdown cleaning against XSS, upload limits, the resale rule, ratings only by verified buyers), a Cypress spec (create a page with images, list an edition, buy, withdraw, rate; an admin hides a reported page), translated UI strings, and the player and admin documentation in English and Russian

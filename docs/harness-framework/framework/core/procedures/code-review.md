# Run a code quality review

1. Read the [code review method]({{rel:documents.codeReviews}}) in full, then the bindings of this project (its tools, commands and dimensions) next to it.
2. Review only what the request names; carry the other dimensions from the last report, and say which.
3. Write one dated report from the report template, with the follow-up table triaged. A review adds the report and changes nothing else; fixes follow in separate pull requests, as tasks.

# 12.2 — Buttons across the client have inconsistent padding and unreadable disabled states.

**Status:** ✅ · **Size:** 3 SP

**Buttons across the client have inconsistent padding and unreadable disabled states.** Found in use: (1) some buttons, such as "Save" and "Cancel", have no horizontal padding, so the label touches the edges and looks cramped; (2) some buttons get a dark background when inactive or disabled while the text stays dark, so the label is unreadable. Audit most buttons across the client (every dialog, form, window and admin page; custom-styled buttons as well as Ant Design ones, including any global CSS that overrides `.ant-btn` padding or disabled colours), find the shared cause, and fix it in one place (theme tokens or a shared button style) instead of per button. Expected: every button has consistent horizontal padding, and every disabled or inactive state keeps a readable contrast (WCAG AA) in both themes. Deliver a component or unit test per fix (padding and disabled colours of the shared style), a Cypress check of a disabled button if a flow covers one, and a `CHANGELOG.md` line

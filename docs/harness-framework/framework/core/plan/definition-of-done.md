# Definition of Done

The definition of done for every task is maintained in one place: [method §4](../method/method.md#4-definition-of-done), with its stack items in the stack file. A task in this plan is
complete only when all of its checklist items hold (tests, the coverage gate of the profile,
lint and typecheck, no dead code, docs updated, merged through a Git Flow PR with green CI).

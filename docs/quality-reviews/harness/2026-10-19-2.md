### H-20261019-18 — The pre-push hook runs the full suite for a push that changes no file

- **Severity:** 🟡 · **Dimension:** D15 (hook defect), D14 · **Effort:** S · **Export impact:** helps
- **Evidence:** `.githooks/pre-push:15-17`. With an empty diff, `files` is empty, and `echo "$files" | grep -qv '\.md$'` matches the empty line,
  so the Markdown-only exit is skipped. Reproduced: `git diff --name-only origin/develop..a62f640` is empty, and the test prints "would run full
  checks". The claim push of this review (an empty commit, as the claim convention makes) ran `db:up`, the typecheck, 3,489 tests and the
  generators.
- **Why it matters:** every task claim costs minutes and needs Docker, and parallel sessions running the suite together compete for the
  database.
- **Fix:** skip an empty file list (`[ -z "$files" ] && continue`) in the loop, with a script test of the hook's file filter.

### H-20261019-20 — The monotonic clock is neither banned nor classified

### 2026-10-12 — task 6.1: canvas map renderer
- **Tasks:** 6.1
- **Branch:** `feature/6.1-map-renderer` — done
- **Decisions / deviations from the plan:** the renderer is framework-free (`client/src/features/map/renderer/`): `camera` (pan/zoom/cell lookup), `aging` (fade by `seenAt`), `palette` (colour fallback), `atlas` (JSON index + image loader; a failed load gives the colour fallback), `sprites` (layers per cell, ghosts), `MapRenderer` (frame scheduling, LOD below zoom 0.5, ownership tint on a scratch canvas, hatching for bots without a link, signal bars, live outline, link overlay, selection). No third-party tileset is downloaded: the atlas is original art generated by `scripts/build-atlas.mjs` (CC0, recorded in `client/public/atlas/LICENSE.md`) and can be swapped without code changes. The renderer takes a `MapCell` model; the mapper from API data comes with 6.2. "Seen N s ago" is `ageSeconds`, formatted by the component that owns the tooltip.
- **Next step:** task 6.2 (map state over sockets, fog of war per user).
- **Verify with:** `npm run typecheck && npm run test:coverage -w client`

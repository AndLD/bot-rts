# Map sprite atlas — licence

`atlas.svg` and `atlas.json` are generated by `scripts/build-atlas.mjs`. The pictures are original work of the
bot-rts project, dedicated to the public domain under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). No third-party artwork is included.

The art can be replaced by any free top-down tileset packed into one image with the same JSON index
(`{ "image": "…", "tileSize": 32, "frames": { "<sprite name>": { "x", "y", "w", "h" } } }`); the sprite names used by
the renderer are the keys of `atlas.json`. When a third-party tileset is added, record its author, source and licence
in this file.

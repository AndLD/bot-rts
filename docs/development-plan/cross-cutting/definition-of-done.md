# Definition of Done

The definition of done for every task is maintained in one place: [`AGENTS.md` §6.5](../../../AGENTS.md). A task in this plan is
complete only when all of its checklist items hold (tests, the coverage gate of the [profile](../../profile.md#2-quality-gates),
lint and typecheck, no dead code, docs updated, merged through a Git Flow PR with green CI).
